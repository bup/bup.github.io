
Updating for a new bup release
==============================

- Make sure the relevant `doc/gen` branch (e.g. `doc/gen/main`) is
  ready.

- `./update-for-bup-release BUP\_SOURCE\_REPO DOC_REF`
  e.g. `./update-for-bup-release ~/src/bup/main doc/gen/main`

- Grep for and fix any other in appropriate references to the previous
  version.
